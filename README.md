# Park Technologies Website

Public marketing website for Park Technologies, built for the current V2
practical IT support positioning.

## Stack

- Astro
- Svelte
- Tailwind CSS
- pnpm

## Local Setup

```sh
pnpm install
```

## Development Commands

```sh
pnpm dev
```

Starts the Astro development server.

```sh
pnpm build
```

Builds the static site.

```sh
pnpm preview
```

Previews the built site locally.

## Public Site Expectations

- Primary navigation is Home, About, and Contact.
- Contact uses `support@parktech.dev`.
- Do not add a contact form backend, scheduling tool, tracking, or analytics
  unless explicitly approved.
- Keep public copy practical, plain-English, and focused on professionals,
  offices, and local teams.

## Repository Safety

Do not commit secrets, credentials, passwords, MFA codes, client data, PHI,
patient information, client case details, financial records, sensitive
screenshots, or private documents to this repository.
